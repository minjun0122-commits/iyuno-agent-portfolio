The OWASP Top 10 is a community-maintained awareness document listing the ten
most critical risks facing web applications. Recent editions emphasize broken
access control as the most frequently observed weakness, followed by
cryptographic failures (previously called "sensitive data exposure") and
injection flaws such as SQL and command injection. The list also tracks
security misconfiguration, vulnerable and outdated components, identification
and authentication failures, software and data integrity failures, security
logging and monitoring failures, and server-side request forgery (SSRF).
Each category is derived from aggregated incident and testing data contributed
by industry partners, so the ranking shifts slowly release to release rather
than every year. Teams typically use the list as a checklist during design
review and as a taxonomy for classifying findings from automated scanners and
manual penetration tests.
