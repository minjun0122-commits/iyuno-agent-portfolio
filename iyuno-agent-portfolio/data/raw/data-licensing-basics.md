When building a corpus for retrieval or fine-tuning, the license attached to
each source document determines what downstream use is permitted. Public
domain and permissively licensed content (such as material under Creative
Commons Attribution or CC0) generally allows reuse with attribution.
Copyleft licenses (such as GPL-family licenses for code, or CC BY-SA for
text) permit reuse but require derivative works to carry the same license.
"All rights reserved" material requires explicit permission or falls back to
narrow exceptions such as fair use, which is jurisdiction-dependent and fact
specific. Good practice for a project corpus is to record, per document, the
source URL, the license or terms of use, and the date it was retrieved, so
that provenance and permitted use can be audited later.
